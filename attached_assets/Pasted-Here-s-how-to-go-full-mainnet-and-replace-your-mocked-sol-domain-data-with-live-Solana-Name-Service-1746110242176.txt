🔎 2. Live Domain Search (Availability + Owner)
Replace your mock search logic with this:

js
Copy
Edit
import {
  getHashedName,
  getNameAccountKey,
  NameRegistryState
} from '@bonfida/spl-name-service';
import { Connection, PublicKey } from '@solana/web3.js';

const connection = new Connection('https://api.mainnet-beta.solana.com');

export async function checkDomain(domain) {
  const name = domain.replace('.sol', '');

  const hashedName = await getHashedName(name);
  const nameAccountKey = await getNameAccountKey(hashedName, undefined);

  try {
    const registry = await NameRegistryState.retrieve(connection, nameAccountKey);
    return {
      available: false,
      owner: registry.owner.toBase58()
    };
  } catch (err) {
    return {
      available: true,
      owner: null
    };
  }
}
🧠 This tells you if a domain is registered, and if it is, returns the owner wallet address.

💡 3. Real Alternatives (Smart Suggestions)
When a domain is taken, suggest:

[name]xyz.sol

its[name].sol

[name]sol.sol

Just modify the above checkDomain() for each suggestion, run in parallel, and display the available ones.
